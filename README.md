# CNN MNIST Classifier

## 📌 توضیح
شبکه‌ی عصبی کانولوشنی (CNN) با PyTorch برای تشخیص عدد دست‌نویس.

## 🎯 نتیجه
- دقت: ۹۹.۱۸٪
- داده: ۶۰,۰۰۰ آموزش + ۱۰,۰۰۰ تست
- پارامترها: ۴۲۱,۶۴۲
- زمان آموزش: ~۵ دقیقه (GPU T4)

## 🛠️ تکنولوژی
- PyTorch
- torchvision
- Kaggle GPU T4

## 📝 درس‌های گرفته‌شده
- Dropout برای جلوگیری از Overfitting
- داده‌ی زیاد = مدل مقاوم
- GPU سرعت آموزش را ۱۰ برابر می‌کند
