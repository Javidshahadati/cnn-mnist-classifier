# cnn-mnist-classifier# CNN MNIST Classifier

## توضیح
یک شبکه‌ی عصبی کانولوشنی (CNN) با PyTorch برای تشخیص عدد دست‌نویس (۰ تا ۹).

## نتیجه
- دقت: ۹۹.۰۷٪
- داده: ۶۰,۰۰۰ تصویر آموزش + ۱۰,۰۰۰ تست
- پارامترها: ۴۲۱,۶۴۲

## تکنولوژی
- PyTorch
- torchvision
- Google Colab (GPU T4)

## درس‌های گرفته‌شده
- Dropout برای جلوگیری از Overfitting
- داده‌ی زیاد = مدل مقاوم
- GPU سرعت آموزش را ۱۰ برابر می‌کند
